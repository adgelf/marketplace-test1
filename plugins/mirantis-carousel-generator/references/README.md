# Instagram Carousel Generator

This Claude skill is provided mainly to test the Mirantis skills repository
processes yet it is useful to maintain some design standards for publishing
slides on Instagram or other social media sites.

It was deliberately build to include both a python script and some assets in the
form of TrueType fonts. Since TrueType fonts might contain executable code, this
will be a reasonable use case to test the security scanner.

The fonts I included are available for download from github and are licensed
under the SIL Open Font License, Version 1.1.
